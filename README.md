# Ping — Corporate Website

The public-facing corporate and investor website for Ping, hosted through GitHub Pages.

**Positioning:** The social network for builders.

## Site structure
- `index.html`: corporate story, product ecosystem, founder profile, pricing, growth scenario, investment overview and app installation CTA.
- `corporate.css`: responsive dark-emerald design system and layout.
- `corporate.js`: lightweight mobile navigation and progressive enhancement.
- Legacy Build Africa Challenge assets (`app.js`, `data.js`, `styles.css`) are retained but are no longer loaded by the corporate homepage.

## Official product destinations
- Ping: https://justping.lovable.app/
- Ping Download Centre: https://justping.lovable.app/download
- DOT: https://dotlive.lovable.app/
- GRIOT AI: https://griot-ai.onrender.com/

## Installation status
The official Download Centre is the canonical installation destination. The current supported installation path is the Progressive Web App (PWA). Do not publish unofficial APKs or imply that a native Android/iOS store release is available until signed/approved builds are published.

## Financial scenario disclosure
The growth and revenue charts are management targets and an illustrative scenario, not actual results or guaranteed outcomes. The six-month cumulative scenario assumes 100,000 verified subscribers in Month 1, 500,000 in Month 2, and 1,000,000 in Months 3–6, with an 80% Builder Plus / 20% Builder Pro mix at monthly prices of $2 and $20 respectively (or ₦3,000 and ₦30,000 for Nigerian users). Figures are gross billings before taxes, payment costs, refunds, churn and other deductions.

## Deployment
GitHub Pages currently serves the `gh-pages` branch from the repository root. Changes should be reviewed on a feature branch and merged to `gh-pages` when approved.
