## 1. Primary Navigation Reconciliation

Ping's primary navigation across desktop (`DesktopSidebar.tsx`), tablet (`SiteHeader.tsx`), and mobile (`BottomNav.tsx`) is verified and locked to the **5 approved destinations**:

1. **Home** (`/`)
2. **Explore** (`/explore`)
3. **Create** (`/create` / `CreateStackModal`)
4. **Hubs** (`/hubs`)
5. **Inbox** (`/messages`)

All additional capabilities (Signals, Clips, Spotlight, Learn, Businesses, Developers, GRIOT AI, DOT Balance, Boosts, Upgrades, Download Centre, Settings, Administration) are cleanly accessible via secondary navigation, Explore discovery pills, Create stack, or profile/account menus without cluttering primary navigation or removing any existing routes.
